# v0.6.34

## English

Release v0.6.34 — app footer with server version and GitHub link.

### Changes

- Added a global footer to the app shell (visible on every page): the server version on the left, fetched from `/api/meta/version`, and a GitHub icon on the right linking to https://github.com/jsllxx77/thism in a new tab.
- The footer stays visible when the version endpoint is unavailable; the version text is simply hidden. Accessible labels are provided for the GitHub link in both English and Chinese.
- Added `docs/release-workflow.md` (en + zh-CN), a step-by-step operator guide for the official tag-driven release process used to produce this release.

### Upgrade note

- No configuration or data changes; just replace the image. Agents auto-update within 30 minutes.

### Assets

- Signed linux/amd64 and linux/arm64 agent binaries are attached.
- Signature and version sidecar files are attached for each agent binary.
- Container images are published to GHCR as v0.6.34, the commit SHA, and latest.

发布 v0.6.34 —— 应用页脚：服务端版本号与 GitHub 链接。

- 每个 agent 二进制文件都附带对应的签名和版本 sidecar 文件。
- 容器镜像已发布到 GHCR，标签包括 v0.6.34、提交 SHA 和 latest。
