# v0.6.31

## English

Release v0.6.31.

### Changes

- Added a built-in server-side proxy for importing themes from GitHub Releases, avoiding browser CORS failures during asset downloads.
- Added a `Use theme` action for every installed theme so imported themes can be selected after installation.
- Persisted and synchronized theme switching through the existing theme settings flow.

### Assets

- Signed linux/amd64 and linux/arm64 agent binaries are attached.
- Signature and version sidecar files are attached for each agent binary.
- Container images are published to GHCR as v0.6.31, the commit SHA, and latest.

## 中文

发布 v0.6.31。

### 更新内容

- 新增服务端 GitHub Release 主题下载代理，避免浏览器下载主题资产时出现跨域错误。
- 已安装主题列表为每个未启用主题新增“使用主题”按钮，导入主题后可以直接切换。
- 主题切换会通过现有主题设置流程持久化并同步。

### 发布产物

- 已附带签名的 linux/amd64 和 linux/arm64 agent 二进制文件。
- 每个 agent 二进制文件都附带对应的签名和版本 sidecar 文件。
- 容器镜像已发布到 GHCR，标签包括 v0.6.31、提交 SHA 和 latest。
