# v0.6.35

## English

Release v0.6.35 — subtle version footer and mobile-friendly dialogs.

### Changes

- The server version and GitHub link (https://github.com/jsllxx77/thism) now sit in a subtle, right-aligned row at the bottom of the page content instead of a full-width footer bar. The version comes from `/api/meta/version` and is hidden gracefully when unavailable; the link opens in a new tab with accessible labels in English and Chinese.
- Dialogs are now scrollable when their content is taller than the viewport (capped at `100dvh` minus a margin with internal scrolling). Previously, on mobile screens, tall dialogs such as the edit-latency-monitor form, batch agent upgrade, node rename/tags, add-node wizard, and notification settings were clipped top and bottom with no way to reach the overflow, because Radix Dialog locks body scroll. This applies to every dialog through the shared `DialogContent` component.

### Upgrade note

- No configuration or data changes; just replace the image. Agents auto-update within 30 minutes.

### Assets

- Signed linux/amd64 and linux/arm64 agent binaries are attached.
- Signature and version sidecar files are attached for each agent binary.
- Container images are published to GHCR as v0.6.35, the commit SHA, and latest.

## 中文

发布 v0.6.35 —— 低调版页脚与移动端弹窗适配。

### 更新内容

- 服务端版本号和 GitHub 链接（https://github.com/jsllxx77/thism）改为页面内容底部一行右对齐的小字，不再是整条全宽页脚栏。版本号来自 `/api/meta/version`，接口不可用时自动隐藏；GitHub 链接新窗口打开，提供中英文无障碍标签。
- 弹窗内容超过视口高度时现在可以内部滚动（高度上限为 `100dvh` 减去边距）。此前在移动端，编辑延迟监测、批量升级 Agent、节点重命名/标签、添加节点向导、通知设置等高弹窗上下被裁切且无法滚动（Radix Dialog 会锁住页面滚动）。修复作用于共用的 `DialogContent` 组件，所有弹窗均生效。

### 升级说明

- 无配置和数据变更，直接替换镜像即可。Agent 会在 30 分钟内自动更新。

### 发布产物

- 已附带签名的 linux/amd64 和 linux/arm64 agent 二进制文件。
- 每个 agent 二进制文件都附带对应的签名和版本 sidecar 文件。
- 容器镜像已发布到 GHCR，标签包括 v0.6.35、提交 SHA 和 latest。
