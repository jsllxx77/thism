## English

Release {{VERSION}}.

### Changes

- Fixed inflated node disk capacity and usage when the same block device is mounted more than once (for example bind mounts). Totals now count each device once across metrics storage, live websocket updates, hardware inventory, and disk alerts.
- Agent metrics now include the block device identity for each mount so servers can de-duplicate bind mounts correctly; older agents without device fields keep the previous per-mount summing behavior.
- Homepage node cards can show since-boot cumulative network traffic totals.
- Storage health on the node detail page is collapsed by default to reduce noise on virtualized hosts.
- Settings display options let admins show or hide system and memory pressure sections.

### Assets

- Signed linux/amd64 and linux/arm64 agent binaries are attached.
- Signature and version sidecar files are attached for each agent binary.
- Container images are published to GHCR as {{VERSION}}, sha-{{SHORT_SHA}}, and latest.

## 中文

发布 {{VERSION}}。

### 更新内容

- 修复同一块物理盘被多次挂载（例如 bind mount）时，节点磁盘总容量和使用量被重复累加的问题。指标入库、实时 WebSocket 推送、硬件档案和磁盘告警现在都会按块设备去重后再统计。
- Agent 上报的每个挂载点现在包含底层块设备标识，服务端可据此正确去重；未上报 device 的旧版 agent 仍按原有“按挂载点相加”的兼容逻辑处理。
- 首页节点卡片可展示自启动以来的累计网络流量。
- 节点详情页的存储健康信息默认收起，减少虚拟化主机上的干扰信息。
- 设置页的显示选项允许管理员开关系统压力和内存压力相关区块。

### 发布产物

- 已附带签名的 linux/amd64 和 linux/arm64 agent 二进制文件。
- 每个 agent 二进制文件都附带对应的签名和版本 sidecar 文件。
- 容器镜像已发布到 GHCR，标签包括 {{VERSION}}、sha-{{SHORT_SHA}} 和 latest。
