## English

Release {{VERSION}}.

### Changes

- Reordered the node detail page so hardware inventory, time range, primary trends, disk health, throughput, pressure diagnostics, latency, and operational details appear in a clearer operational sequence.
- Disk health stays visible for physical, mixed, warning, critical, or unknown devices, but defaults collapsed when every reported disk is an unsupported virtual/cloud disk.
- Clarified virtualized storage health reporting: cloud or virtual disks may not expose host SMART/NVMe health, while capacity, mount, read-only, and I/O counters continue to be monitored.
- Release publishing now requires hand-authored bilingual release notes before a tag can publish.

### Assets

- Signed linux/amd64 and linux/arm64 agent binaries are attached.
- Signature and version sidecar files are attached for each agent binary.
- Container images are published to GHCR as {{VERSION}}, sha-{{SHORT_SHA}}, and latest.

## 中文

发布 {{VERSION}}。

### 更新内容

- 调整节点详情页的信息顺序，让硬件信息、时间范围、核心趋势、硬盘健康、吞吐、压力诊断、延迟和运行细节按更清晰的运维查看顺序展示。
- 硬盘健康在物理盘、混合磁盘、告警、严重或未知状态下仍默认展开；如果节点只上报不支持硬件健康的虚拟盘/云盘，则默认收起这张卡片，减少无效信息占用页面。
- 明确虚拟化存储的健康说明：云盘或虚拟盘通常不会暴露宿主机的 SMART/NVMe 健康数据，但容量、挂载点、只读状态和 I/O 计数仍会继续监控。
- 发布流程现在要求每个版本在打 tag 前提供手写的中英文发布说明，避免中文发布内容再次变成英文提交标题。

- 每个 agent 二进制文件都附带对应的签名和版本 sidecar 文件。
