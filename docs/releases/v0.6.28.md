## English

Release {{VERSION}}.

### Fixes

- Fixed Docker Compose GeoIP database updates by mounting the host GeoIP directory as writable instead of read-only.
- The one-command Compose installer now detects the selected image's runtime UID/GID, prepares `THISM_GEOIP_HOST_DIR` with matching ownership, and verifies that the container can write to it before startup.
- Added safety checks that reject the filesystem root and parent-directory traversal in installer-managed GeoIP paths.
- Updated the deployment and GeoIP documentation for writable managed databases and manual directory preparation.

### Assets

- Signed linux/amd64 and linux/arm64 agent binaries are attached.
- Signature and version sidecar files are attached for each agent binary.
- Container images are published to GHCR as {{VERSION}}, sha-{{SHORT_SHA}}, and latest.

## 中文

发布 {{VERSION}}。

### 修复内容

- 修复 Docker Compose 环境无法从设置页更新 GeoIP 数据库的问题，主机 GeoIP 目录不再以只读方式挂载。
- 一键 Compose 安装器现在会读取所选镜像的实际运行 UID/GID，为 `THISM_GEOIP_HOST_DIR` 设置匹配的目录所有权，并在启动前确认容器具备写权限。
- 安装器新增路径安全检查，拒绝把文件系统根目录或包含父目录跳转的路径用作 GeoIP 数据目录。
- 同步更新部署与 GeoIP 文档，说明可写数据库挂载和手动目录初始化方式。

### 发布产物

- 已附带签名的 linux/amd64 和 linux/arm64 agent 二进制文件。
- 每个 agent 二进制文件都附带对应的签名和版本 sidecar 文件。
- 容器镜像已发布到 GHCR，标签包括 {{VERSION}}、sha-{{SHORT_SHA}} 和 latest。
