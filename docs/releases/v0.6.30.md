# v0.6.30

## English

Release v0.6.30.

### Changes

- The appearance system now keeps Classic as the only built-in baseline.
- Theme changes are limited to importing a validated theme zip from a GitHub repository's latest release or uploading a local zip archive.
- Removed the Theme Plugin, Frontend Skin, and Shadcn Operations management surfaces and runtime integration.
- Added theme archive validation, import APIs, persistence cleanup, and migration of retired theme data.
- Simplified the settings appearance page and removed direct theme switching and deletion controls.

### Assets

- Signed linux/amd64 and linux/arm64 agent binaries are attached.
- Signature and version sidecar files are attached for each agent binary.
- Container images are published to GHCR as v0.6.30, sha-{{SHORT_SHA}}, and latest.

## 中文

发布 v0.6.30。

### 更新内容

- 外观系统现在仅保留 Classic 作为唯一内置基线主题。
- 主题只能通过 GitHub 仓库最新 Release 中经过校验的主题 zip，或本地上传的主题 zip 进行更改。
- 移除 Theme Plugin、Frontend Skin、Shadcn Operations 的管理界面与运行时集成。
- 新增主题压缩包校验、导入 API、持久化清理，以及废弃主题数据迁移。
- 简化设置中的外观页面，移除直接切换和删除主题的操作入口。

### 发布产物

- 已附带签名的 linux/amd64 和 linux/arm64 agent 二进制文件。
- 每个 agent 二进制文件都附带对应的签名和版本 sidecar 文件。
- 容器镜像将发布到 GHCR，标签包括 v0.6.30、sha-{{SHORT_SHA}} 和 latest。
